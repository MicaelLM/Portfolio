# 💼 Portfolio

> Site pessoal com meu portfólio e informações profissionais — 2026.

🔗 **Acesse online:** [micaellm.github.io/Portfolio](https://micaellm.github.io/Portfolio/)

## 💡 Sobre

Site estático, construído com HTML e CSS puros, apresentando minha trajetória profissional e acadêmica: formação, experiências e instituições/empresas por onde passei.

## 🛠️ Tecnologias

- HTML5
- CSS3

## 📁 Estrutura

```
├── index.html    # Página principal do portfólio
├── style.css     # Estilos do site
└── *.png / *.jpg / *.ico   # Logos e imagens usados no site
```

## 🚀 Como visualizar

```bash
git clone https://github.com/MicaelLM/Portfolio.git
cd Portfolio
```

Depois é só abrir o `index.html` no navegador — não há dependências ou build necessário.

## 🌐 Deploy

O site é publicado automaticamente via **GitHub Pages**, a partir da branch `main`.
